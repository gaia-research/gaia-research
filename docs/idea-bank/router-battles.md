# Router Battles: The Agent Routing Arena ⚔️

- **Status:** Unranked / playful idea; **not authorized to run**
- **Tracking:** [#323](https://github.com/gaia-research/gaia-research/issues/323)
- **Companion formal research:** [Router Economics](./router-economics-human-vs-automated-routing.md)

## Premise

An accessible, high-energy **1v1 router showdown** where even a human can enter the arena: “this is a Luna task,” “this needs Opus,” or “let Flash choose.” The human is a **white-box** contestant: record the choice and reasoning before any outcome is known.

Sample brackets: Human vs JEV; JEV vs Pi Orchestrator; Fixed Rules vs OpenRouter Auto Code; Single Fixed Model vs NVIDIA Switchyard. Vary task types so a router can win one matchup and lose another.

Each informal battle card records the exact task, router/model versions, predeclared eligibility, why each participant chose its route, actual execution outcome, tests/reviewer verdict, total tokens, API-equivalent cost (separate from quota), time, retries and uncertainty. Keep both failures and upsets; invite rematches and a playful leaderboard.

**Scientific firewall:** These are exploratory demos, not a paper, product superiority claim or definitive benchmark. A single win cannot establish the best router. No router wars content published or API spending without later explicit approval.
